# Proyecto MLOps: Clasificación y Gestión de Experimentos con MLflow

## Descripción del Proyecto
Este proyecto implementa un flujo completo de Machine Learning (MLOps) enfocado en la reproducibilidad, el versionamiento y la trazabilidad de experimentos. Se compara el rendimiento entre una **Regresión Logística** y un **Random Forest Classifier** para predecir la presencia de enfermedades cardíacas.
